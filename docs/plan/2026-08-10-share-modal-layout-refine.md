# 分享房间弹窗布局细化 PRD

## Problem Statement

分享房间弹窗中二维码两侧空白过宽，房间号不够醒目且位置不符合过渡页视觉规范，底部三个复制操作的按钮边界不明显。需要在保持二维码尺寸和复制能力不变的前提下，改善弹窗比例与操作识别度。

## Solution

将分享房间 Modal 桌面宽度调整为 `420px`，移动端继续自适应。二维码保持现有尺寸，利用更窄的弹窗内容区减少左右空白。房间号移至二维码正上方居中显示，复用过渡页的等宽字体、大字号、加粗和主题强调色。桌面端三个复制按钮维持一行三列等宽布局；移动端纵向排列。

## User Stories

1. 作为桌面端用户，我希望分享弹窗更紧凑，以便二维码两侧不留过多空白。
2. 作为房间用户，我希望房间号位于二维码上方且醒目，以便快速确认分享目标。
3. 作为用户，我希望房间号样式与过渡页一致，以便不同页面视觉统一。
4. 作为桌面端用户，我希望三个复制按钮保持一行显示，以便操作关系清晰。
5. 作为移动端用户，我希望三个复制按钮在窄屏纵向排列，以便文字不被挤压。
6. 作为用户，我希望二维码尺寸保持不变，以便扫码识别体验不受影响。
7. 作为中文或英文用户，我希望现有复制按钮文案继续正常显示。
8. 作为深色主题用户，我希望房间号主题色和按钮对比度保持可读。

## Implementation Decisions

- 仅修改分享房间 Modal 的宽度为 `420px`；个人中心、容量详情和其他弹窗不变。
- 保留 Ant Design Modal 的遮罩点击、关闭按钮和 Esc 关闭行为。
- 将房间标题保留在分享内容顶部左侧。
- 将房间号拆分为标签和号码，号码居中放在二维码正上方。
- 房间号号码沿用过渡页规范：等宽字体、`font-weight: 800`、`letter-spacing: 0.16em`、响应式大字号、主题强调色。
- 二维码 SVG 宽度规则保持不变，不修改二维码数据和请求逻辑。
- 分享内容左右内边距继续收窄，使固定二维码在 `420px` Modal 中获得更小侧边空白。
- 桌面端复制操作使用三列等宽网格；保留三个按钮及其复制值。
- 在窄屏媒体查询下将复制操作切换为单列，避免中英文长文案溢出。
- 不修改复制工具、翻译键、后端接口、数据库、SSE 或路由。

## Testing Decisions

- 验证桌面分享弹窗宽度为 `420px`，二维码尺寸与调整前一致。
- 验证房间号在二维码上方居中、字号和颜色符合过渡页规范。
- 验证桌面三个复制按钮一行三列且边框清晰。
- 验证移动窄屏三个按钮纵向排列，无横向溢出。
- 分别验证三个按钮复制房间号、分享链接和邀请信息的值不变。
- 验证中文、英文、浅色和深色主题下内容可读。
- 运行现有前端测试、TypeScript 检查和生产构建。

## Out of Scope

- 不调整二维码尺寸、二维码生成接口或分享链接格式。
- 不修改个人中心、容量详情和其他 Modal 的宽度。
- 不新增复制操作、图标、翻译键或后端能力。

## Further Notes

- `420px` 只针对分享弹窗，用于在二维码尺寸不变时压缩两侧空白。
- 当前项目处于开发阶段，无数据迁移和兼容处理。
