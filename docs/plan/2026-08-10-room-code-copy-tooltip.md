# 房间号复制 Tooltip 优化 PRD

## Problem Statement

房间页左侧成员面板中，复制房间号后的成功或失败提示显示在按钮下方。提示出现时会增加房间信息区域高度，造成布局跳动；提示样式也与项目现有 Ant Design 交互反馈不统一。

## Solution

将房间号复制成功和失败反馈改为 Ant Design Tooltip。Tooltip 绑定房间号复制按钮并显示在按钮上方，状态产生时主动打开，约 `1.5s` 后自动隐藏。移除原有下方提示文字，使左侧区域尺寸保持稳定。

## User Stories

1. 作为房间用户，我希望复制房间号后立即看到成功提示，以便确认操作结果。
2. 作为复制失败的用户，我希望在同一位置看到失败提示，以便知道需要重试。
3. 作为桌面端用户，我希望提示出现时左侧成员区域不发生布局跳动，以便页面保持稳定。
4. 作为键盘或鼠标用户，我希望提示靠近复制按钮，以便快速理解反馈属于哪个操作。
5. 作为中文或英文用户，我希望继续使用现有双语提示，以便无需识别新增文案。
6. 作为深色主题用户，我希望 Tooltip 使用 Ant Design 主题样式，以便保持可读性。

## Implementation Decisions

- 在房间号复制按钮外包裹 Ant Design Tooltip。
- Tooltip 固定使用顶部位置，避免遮挡下方成员列表。
- Tooltip 使用受控打开状态：复制成功或失败后打开，约 `1.5s` 后清除状态并关闭。
- 成功内容使用现有“已复制”翻译键，失败内容使用现有“复制失败”翻译键。
- 复制开始前清除旧反馈，避免连续操作残留上一次提示。
- 成功和失败状态互斥；任一状态只对应一条 Tooltip 内容。
- 移除房间号按钮下方的成功和失败 `<small>` 文本。
- 保留现有复制工具，继续支持通过 `127.0.0.1` 或局域网 IP 访问时复制。
- 不修改房间号内容、按钮图标、按钮点击范围和房间信息结构。
- 不新增用户文案或翻译键。
- 不修改后端、数据库、API、SSE 或路由。

## Testing Decisions

- 测试用户可观察行为，不测试 Ant Design 内部实现。
- 人工验证复制成功后 Tooltip 在按钮上方出现，约 `1.5s` 后消失。
- 人工验证复制失败时显示失败 Tooltip，且不会同时显示成功内容。
- 验证提示出现和消失时房间信息区域高度不变。
- 验证连续点击不会导致多个计时状态叠加出错。
- 验证中文、英文、浅色和深色主题下提示可读。
- 运行现有前端测试、TypeScript 检查和生产构建。
- 本次不新增业务逻辑测试；复制兼容工具本身不变。

## Out of Scope

- 不修改复制实现或浏览器兼容降级方案。
- 不修改分享链接、邀请文案或其他复制入口。
- 不调整成员列表、房间标题或房间号样式。
- 不新增全局消息通知。

## Further Notes

- Tooltip 只承担操作结果反馈，不应依赖鼠标悬停才能看到。
- 当前项目处于开发阶段，本次无兼容或数据迁移处理。
