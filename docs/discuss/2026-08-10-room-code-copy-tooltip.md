# 房间号复制提示优化讨论

## 原始需求

用户提供房间页左侧房间号区域截图，要求将复制提示信息改为 Ant Design Tooltip 形式。

## 代码检查结论

- 房间号复制入口位于房间页左侧成员面板。
- 当前复制成功或失败后，会在复制按钮下方渲染 `<small>` 文本。
- 下方文本会占用额外高度，导致房间信息区域产生布局变化。
- 项目已有兼容非安全上下文的复制工具，复制业务逻辑不需要调整。

## 逐项确认

### 问题 1：提示覆盖范围

- 建议：复制成功和复制失败都统一使用 Ant Design Tooltip，避免两种状态采用不同布局。
- 用户回答：确认。

### 问题 2：Tooltip 位置和时长

- 建议：Tooltip 显示在房间号复制按钮上方，成功或失败后自动显示约 `1.5s`，随后隐藏。
- 用户回答：确认。

## 最终共识

使用 Ant Design Tooltip 包裹房间号复制按钮。复制成功时显示现有“房间号已复制”文案，复制失败时显示现有“复制失败”文案；Tooltip 放在按钮上方，状态持续约 `1.5s` 后清除。移除按钮下方的提示文本，不修改复制工具、复制内容或其他房间信息。
