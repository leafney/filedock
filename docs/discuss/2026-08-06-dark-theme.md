# 深色主题与主题切换讨论纪要

## 原始需求

下一阶段考虑实现整个页面的深色主题，支持主题切换效果。

## 逐项确认

### 1. 主题模式

- 问题：支持哪些模式？
- 推荐：浅色/深色两种，首次跟随系统，手动选择后保存本地。
- 答案：支持“深色、浅色、跟随系统”三种模式，默认“跟随系统”。

### 2. 生效范围

- 问题：是否覆盖整个前端应用？
- 推荐：首页、房间页、全局栏、文件区、聊天区、成员列表、通知中心及所有浮层状态均覆盖；不修改文件内容和操作系统原生文件窗口。
- 答案：确认覆盖整个前端。

### 3. 品牌与语义颜色

- 问题：是否保留青绿色品牌色和功能状态色？
- 推荐：保留品牌色及语义含义，深色模式下调整明度和对比度；使用深灰蓝层级，不使用纯黑。
- 答案：确认。

### 4. 跟随系统行为

- 问题：系统主题变化时是否即时更新？
- 推荐：监听 `prefers-color-scheme`，跟随系统时即时切换；手动模式覆盖系统；异常本地值回退跟随系统。
- 答案：确认。

### 5. 切换动画

- 问题：是否需要主题切换过渡？
- 推荐：约 180ms 颜色过渡；遵守 `prefers-reduced-motion`；首次加载不播放动画。
- 答案：确认。

### 6. 菜单结构

- 问题：主题模式如何放入头像菜单？
- 推荐：头像下拉中的“主题模式”二级菜单，列出跟随系统、深色、浅色；点击后立即生效并关闭菜单，文案支持中英文。
- 答案：确认；当前模式不用勾选标记，改为选项前的圆点标记。

### 7. 多标签页同步

- 问题：多个标签页是否同步？
- 推荐：监听 `storage` 事件同步，不涉及后端和跨设备。
- 答案：确认 localStorage 由同一浏览器标签页共享，继续按此实现。

### 8. Canvas 内容

- 问题：雷达 Canvas 等非 DOM 内容是否适配？
- 推荐：深色模式调整雷达网格、文字、轨迹和背景对比度；头像、缩略图和文件内容保持原样。
- 答案：确认。

### 9. 浏览器级主题

- 问题：是否同步浏览器级表现？
- 推荐：动态更新 `meta theme-color`，设置 `color-scheme`，适配滚动条和原生控件。
- 答案：确认。

### 10. 验证方式

- 问题：是否以手动验证为主？
- 推荐：手动覆盖主要页面、浮层、移动端和三种模式；仅为主题解析、系统响应、非法值回退等纯逻辑补单元测试，不做 Playwright 或大规模截图测试。
- 答案：确认。

### 11. 浅色主题兼容

- 问题：浅色主题是否保持现有视觉？
- 推荐：保持颜色、间距、布局和交互不变，仅将固定颜色收敛为变量；必要时只修正对比度。
- 答案：确认。

### 12. 技术架构

- 问题：是否采用统一主题状态、Ant Design 深色算法和 CSS 变量？
- 推荐：根部 ThemeProvider/Hook 管理模式、本地存储、系统监听、跨标签同步；ConfigProvider 使用 `darkAlgorithm`；根节点设置 data-theme；组件不散落主题判断或硬编码颜色。
- 答案：确认。

### 13. 无障碍

- 问题：主题菜单是否支持键盘和无障碍？
- 推荐：使用 Ant Design 可选菜单机制，提供选中状态和键盘操作；视觉上仍只显示圆点。
- 答案：确认。

### 14. 视觉参考与色值

- 问题：是否提供外部设计稿或固定色值？
- 推荐：不引入外部设计稿、不锁死具体色值，基于现有品牌色建立深灰蓝调色板，以对比度和一致性验收。
- 答案：确认。

## 最终共识

FileDock 新增全前端三态主题系统：跟随系统（默认）、深色、浅色。主题入口位于右上角用户头像下拉菜单的“主题模式”二级菜单，三项前以单选圆点显示当前模式。主题偏好保存于 localStorage，同一浏览器标签页通过 storage 事件同步；跟随系统时实时响应 `prefers-color-scheme`。主题覆盖所有自定义页面、Ant Design 组件和浮层、Canvas 雷达及浏览器级主题表现。保留现有浅色视觉、品牌青绿色和语义颜色含义，深色使用深灰蓝层级并保证对比度。切换提供约 180ms 过渡并尊重减少动画偏好，首次加载避免闪烁。实现采用统一 ThemeProvider/Hook、Ant Design darkAlgorithm 和 CSS 变量；新增文案完整支持 zh-CN/en。验证以手动测试为主，补充主题纯逻辑单元测试，不改后端、数据库或文件内容渲染。
