# 深色主题局部显示问题优化讨论纪要

## 原始需求

经手动测试发现深色模式仍有局部问题：房间右侧聊天区域默认白色；选中用户后的聊天输入框白色且输入内容难以看清；批量选择按钮未选中时为白色；文件信息弹窗标题区域为白色。需要分析并优化。

## 逐项确认

### 1. 聊天区域层级

- 推荐：聊天整体使用深色页面背景，顶部用户栏和底部输入区使用稍亮面板，消息区使用深色渐变，空态使用灰蓝色。
- 答案：确认。

### 2. 聊天输入框

- 推荐：输入区和 textarea 使用独立深色层；文字浅灰白、占位符灰蓝色、边框深灰蓝，聚焦使用青绿色描边，发送按钮保留青绿色。
- 答案：确认。

### 3. 批量选择按钮

- 推荐：未选中使用深色背景、深灰蓝边框和灰蓝文字；悬停转青绿色；选中使用青绿色边框、深青绿色背景和青绿色文字；桌面端与移动端一致。
- 答案：确认。

### 4. 弹窗标题区

- 代码确认：截图中的文件信息弹窗是自定义 `.room-overlay > section > header`，项目还存在 Ant Design Modal/Drawer。
- 推荐：统一修复自定义弹窗和 Ant Design Modal/Drawer 的标题区、内容区、底部操作区；关闭按钮使用灰蓝色，悬停青绿色；浅色不变。
- 答案：确认。

### 5. 文件信息内容对比度

- 推荐：信息卡片使用深色表面，字段标签灰蓝色，字段值浅灰白，文件名/大小/上传者等关键值提高对比度，保持布局。
- 答案：确认。

### 6. 批量控件

- 推荐：原生复选框匹配主题并使用青绿色选中态；批量操作栏使用深青绿色背景；批量下载/发送按钮使用深色表面和青绿色描边；禁用态灰蓝色。
- 答案：确认。

### 7. 验证方式

- 推荐：手动验证四个截图场景，并额外检查聊天消息、移动端聊天、Ant Design Modal/Drawer；运行 `bun test`、`bun run build`、`git diff --check`；不改后端/数据库、不引入端到端测试。
- 答案：确认。

## 最终共识

本次只修复深色主题的局部显示问题，不改变浅色模式布局和视觉，不增加业务逻辑。重点是让聊天空态、聊天工作区、聊天输入区、批量选择及操作控件、自定义文件信息弹窗和 Ant Design 浮层都使用统一深色层级与可读对比度。修复应通过现有主题变量和深色 CSS 覆盖完成，必要时调整组件主题配置；用户手动验收为主，前端测试和生产构建作为回归门槛。
