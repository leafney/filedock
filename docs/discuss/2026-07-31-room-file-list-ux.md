# 房间文件列表交互优化讨论记录

- 日期：2026-07-31
- 状态：已达成共识
- 讨论对象：独立房间工作区原型

## 原始需求

用户查看房间工作区原型和两张局部截图后提出四项问题：

1. 文件列表右侧操作区域按钮过多，希望保留下载按钮与三个点入口，其他操作通过三个点打开二级菜单。
2. 顶部“上传共享文件／定向发送／选择已有文件”三个按钮的职责不清晰，难以理解操作方式。
3. 中间文件列表虽然支持拖放上传，但页面缺少持续可见的拖放提示，用户无法一眼理解该能力。
4. 共享文件和定向文件只通过范围字段区分且混在同一列表，用户考虑是否拆成共享文件列表和定向文件列表。

用户要求先查看原型相关代码，分析后给出优化方案，并使用 `grill-me` 逐项收敛设计。

## 代码核对结论

- 当前文件列表先经过统一权限投影，再按文件范围筛选与排序。
- 共享和私密文件使用同一文件集合，范围状态分别为内部值 `shared` 与 `direct`。
- 文件列表、文件动态和回收站共享同一身份投影规则。
- 当前顶部三个按钮混合了两个不同维度：本地／历史文件来源，以及共享／私密发送范围。
- 当前文件表格整体已是拖放目标，但常驻状态没有明显视觉提示；只有文件真正拖入时才显示覆盖层。
- 当前操作列直接并排渲染所有权限允许的操作，导致窄屏换行和视觉噪声。

## 完整问答记录

### 问题 1：是否拆成两个完全独立的文件页面？

推荐答案：不拆成两套独立页面。保留一个逻辑文件列表，在内部提供“全部／共享文件／私密文件”，全部模式按共享和私密分组展示。

用户回答：确认。

### 问题 2：顶部上传入口如何简化？

推荐答案：只保留“添加文件”和“发送已有文件”两个入口。添加本地文件后在待发送区选择共享或私密；聊天附件仍自动进入私密发送并预选当前成员。

用户回答：确认。

### 问题 3：如何持续表达拖放能力？

推荐答案：文件列表内增加常驻紧凑拖放条，拖入时再显示覆盖整个中间工作区的高亮层；移动端隐藏拖放条。

用户回答：确认，但要求去掉辅助文字，只保留“拖放文件到这里，或点击添加文件”。

### 问题 4：文件主操作按钮是否随状态变化？

推荐答案：普通文件显示下载与三个点；上传中文件显示查看进度与三个点；匿名私密文件只显示三个点；待接收私密文件根据接收语义显示主操作。

用户回答：确认，但要求待接收私密文件直接显示“接收并下载”和“拒绝”两个按钮。

### 问题 5：待接收私密文件是否还显示三个点？

推荐答案：不显示。待接收阶段只有接受与拒绝两个有效决策；接收完成后再恢复“下载＋三个点”。

用户回答：确认。

### 问题 6：桌面三个点菜单如何组织？

推荐答案：使用右对齐下拉菜单；提供查看文件信息，并按身份显示再次发送、发布共享、查看接收状态和治理操作；危险操作固定在底部并使用红色；无权限操作不渲染；同一时间只打开一个菜单；支持点击外部和 Escape 关闭。

用户回答：确认。

### 问题 7：移动端三个点菜单如何展示？

推荐答案：使用底部操作面板，顶部显示文件摘要，中部纵向排列允许操作，危险操作独立分组，底部提供取消；待接收的两个决策仍直接显示在卡片上。

用户回答：确认。

### 问题 8：分组后是否保留桌面“范围”列？

推荐答案：桌面删除独立范围列，以分组标题、文件副标题和匿名审计样式表达范围；移动端卡片继续保留共享／私密／匿名审计标签。

用户回答：确认。

### 问题 9：全部模式下如何排序和折叠？

推荐答案：共享文件固定在上、私密文件固定在下；排序分别作用于两个分组内部；两个分组默认展开且允许折叠；单范围视图不显示折叠按钮。

用户回答：确认。

### 问题 10：用户界面术语是否统一？

推荐答案：用户界面统一使用“共享文件／私密文件／私密发送／私密文件编号”，不再显示“定向”；代码内部继续使用 `shared` 与 `direct`。

用户回答：确认。

### 问题 11：添加文件时如何预选发送范围？

推荐答案：共享文件视图默认共享，私密文件视图默认私密，全部视图默认共享；无论如何都必须进入待发送区确认，私密发送必须选择接收者。

用户回答：确认。

### 问题 12：文件动态和回收站是否也接受拖放？

推荐答案：整个中间工作区都接受拖放，释放后打开待发送区；关闭待发送区后返回原视图；常驻拖放条只在文件列表显示。

用户回答：确认。

### 问题 13：房主匿名私密文件是否单独形成第三分组？

推荐答案：不增加第三分组。匿名记录仍属于私密文件，通过黄色治理行、匿名名称和匿名审计标签区分，继续参与私密分组的排序。

用户回答：确认。

### 问题 14：拒绝接收是否二次确认？

推荐答案：需要轻量确认，展示文件、发送者、大小和拒绝后果；接收并下载不二次确认。

用户回答：确认。

### 问题 15：主文件列表是否常驻复选框？

推荐答案：默认不显示。用户点击“批量选择”后进入临时批量模式并显示复选框与批量操作栏；发送已有私密文件使用独立多选器。

用户回答：确认，并补充默认通常操作单个文件，只有切换到批量选择后才显示复选框支持多选。

### 问题 16：共享与私密文件混合选择时如何处理？

推荐答案：允许跨分组选择，但每个批量操作必须由全部已选文件共同满足权限；不自动忽略无权限文件，也不自动拆分批次；禁用时显示原因。

用户回答：确认。

### 问题 17：文件列表顶部控件如何排列？

推荐答案：桌面和平板使用“全部／共享文件／私密文件＋搜索＋排序＋批量选择”，下一行显示拖放条；数量进入分组标题。移动端第一行范围切换，第二行搜索和选择，排序收入筛选或更多菜单，不显示拖放条。

用户回答：确认。

## 最终共享理解

### 信息架构

- 顶层继续使用“文件列表／文件动态／回收站”。
- 文件列表内部增加“全部／共享文件／私密文件”。
- 全部模式在同一页面中分为共享与私密两个可折叠区块；不创建两套文件页面，不改变统一权限投影。
- 文件动态与回收站继续保持统一视图，不按文件范围拆成多个页面。

### 顶部与拖放

- 顶部操作简化为“添加文件”和“发送已有私密文件”。
- 添加文件只确定文件来源；共享或私密范围在待发送区确认。
- 文件列表显示一条常驻可点击拖放条，文字只有“拖放文件到这里，或点击添加文件”。
- 中间工作区所有顶层视图均可接收拖放；移动端不展示拖放入口。

### 文件列表与操作

- 桌面删除范围列，移动端保留范围标签。
- 普通文件显示“下载＋三个点”；待接收私密文件显示“接收并下载＋拒绝”，不显示三个点。
- 桌面三个点打开下拉菜单；移动端打开底部操作面板。
- 拒绝接收需要二次确认。
- 普通模式不显示复选框；进入批量模式后才显示，并按全部已选文件的共同权限决定可用操作。

### 术语与权限

- 用户界面统一使用“私密”，不再显示“定向”。
- 内部状态值与权限模型保持不变。
- 房主匿名记录保留在私密文件分组中，继续使用匿名投影，不泄露原始元数据。
