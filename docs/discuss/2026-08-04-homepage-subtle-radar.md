# 首页轻量全域雷达波优化讨论记录

- 日期：2026-08-04
- 状态：已达成共识
- 讨论范围：首页雷达波视觉强度、全域扩散范围、波纹数量与节奏、移动端降级、节点呼吸
- 前置规格：`docs/plan/2026-08-03-homepage-water-ripple.md`

## 原始需求

用户对 2026-08-03 水波纹修订版进行人工验收后提供首页截图，并提出以下问题：

1. 当前雷达水波纹仍然过于明显，已经成为首页视觉焦点，影响昵称设置、房间列表等主要操作。
2. 用户更喜欢早期版本“微微可见”的背景氛围；当前水波纹效果不如最初讨论的雷达波效果。
3. 当前可见圆环仍集中在雷达画布中间，红框所示的整个右侧雷达区域没有被纳入传播范围。
4. 外侧房间节点位于明显圆环之外，看不出这些节点属于雷达发现范围。
5. 用户要求继续使用 `grill-me`，逐项确认新的优化方向，暂不直接修改代码。

## 截图与代码分析

- 截图红框表示首页右侧完整雷达面板，而不是“雷达面板宽度的 80%”。前一轮把“右侧 80%”理解为面板内部宽度 `80%`，属于范围理解错误。
- 当前最大直径按面板宽度 `80%` 计算。对于矩形面板，即使终点完全可见，也无法覆盖上下边缘和四角。
- 当前五个波纹使用 `5s` 周期和 `1s` 错峰，透明度在 `10%` 与 `62%` 两次增强到 `45%` 和 `35%`。第二次加深使中段圆环长期清晰，仍具有明显水波和靶环感。
- 当前最大直径只在动画 `100%` 到达，而此时透明度为 `0`。用户实际可见的主要圆环位于 `62%` 附近，因此视觉覆盖范围远小于数学终点。
- 当前圆环除 `1px` 青绿色边框外，还带 `5px` 同色柔光。柔光扩大边缘面积，进一步提高视觉权重。
- 当前 DOM 渲染五个波纹元素。改为四个波纹只需减少一个装饰元素和修改 CSS 延迟，不影响业务状态。
- 当前已有 `ResizeObserver` 同时获得雷达画布宽度和高度。可直接使用勾股计算面板对角线，无需新增观察器或 React 状态。
- 当前桌面与移动端共用同一波纹透明度；需要通过移动端媒体查询进一步降低峰值。
- 当前节点呼吸峰值为 `1.08`。用户认为不够明显，希望提高到 `1.12`；现有节点避让间距足以容纳增加的缩放幅度。

## 完整问答记录

### 问题 1：是否继续保留“深、浅、深、浅”的水波模型？

推荐答案：放弃水波式二次加深，改为低对比度单峰雷达脉冲。波纹从中心出现后向外扩散，并在整个传播过程中持续变浅。

用户回答：确认。

### 问题 2：扩散终点如何覆盖整个红框雷达区域？

推荐答案：最大直径按雷达面板对角线约 `105%` 计算，而不是按宽度或较短边计算。这样圆形波纹能够扫过红框四角和所有外侧房间节点，超出部分继续由雷达画布裁剪。

用户回答：确认。

### 问题 3：桌面雷达波强度如何设置？

推荐答案：回到微微可见的背景强度。透明度从 `0` 快速达到 `12%`，中段约 `6%`，外段约 `2%`，终点回到 `0`；删除柔光，只保留 `1px` 青绿色细线。

用户回答：确认。

### 问题 4：波纹数量、周期与错峰如何设置？

推荐答案：使用四个雷达波实例；单圈周期 `8s`；每 `2s` 发射一圈；保持匀速扩散；使用负延迟让首屏已有完整错峰波列。范围扩大后使用更慢周期，避免波纹快速扫动。

用户回答：确认。

### 问题 5：单圈渐淡关键帧如何设置？

推荐答案：`0%` 完全透明，`8%` 达到 `12%` 峰值，`55%` 降到 `6%`，`92%` 降到 `2%`，`100%` 完全透明。波纹接近外侧节点时仍微弱可见，扫过后才消失。

用户回答：确认。

### 问题 6：雷达波扫过房间节点时，节点是否联动？

推荐答案：不联动。节点不闪烁、不放大、不变色，只让细线从节点后方经过。节点响应容易重新抢占焦点，也会被误解为可点击状态或通知。

用户回答：确认。

### 问题 7：减少动态效果模式如何处理？

推荐答案：保留三圈静态雷达环，透明度为 `5% / 3% / 1%`，分别分布在中心、中段和外侧；停止雷达扩散、节点呼吸以及节点进入退出动画。

用户回答：确认。

### 问题 8：移动端是否使用相同强度？

推荐答案：范围、`8s` 周期和 `2s` 错峰保持一致，但峰值从桌面 `12%` 降到 `8%`。移动端画布更小，进一步减弱可避免干扰昵称和房间操作。

用户回答：确认。

### 问题 9：房间节点呼吸是否保持当前峰值？

推荐答案：保持当前 `1.08`，让节点继续承担局域网活跃感。

用户回答：不采用。当前呼吸仍不明显，希望把峰值从 `1.08` 提高到 `1.12`。

最终决定：节点本体呼吸使用 `1 → 1.12 → 1`，无外扩光圈；标签不缩放。

### 问题 10：提高呼吸峰值后，周期是否变化？

推荐答案：继续保持 `2.8～4.2s` 的五节点错峰周期，只增加缩放幅度。若同时加快速度，节点会产生跳动感。

用户回答：确认。

### 问题 11：是否结束讨论并创建独立增量文档？

推荐答案：创建 2026-08-04 独立讨论记录与增量 PRD，保留前两轮水波方案及验收历史，不再覆盖旧文档。

用户回答：确认。

## 最终共享理解

### 动效方向

- 水波纹模型终止，不再使用二次加深或“深、浅、深、浅”透明度节奏。
- 新模型为轻量单峰雷达波：从中心快速显现，随后向外匀速扩散并持续渐淡。
- 雷达波只承担背景氛围，首页主要视觉焦点应回到操作卡、用户身份和房间节点。

### 全域扩散

- 起点继续使用约 `132px` 直径，与 `112px` 中心头像保持单侧约 `10px` 间距。
- 最大直径为雷达面板对角线约 `105%`。
- 终点由面板宽度和高度共同计算，保证波纹能够扫过四角和所有合法节点位置。
- 超出矩形面板的圆环部分由雷达画布自然裁剪，不影响左侧操作栏、顶栏或页脚。

### 桌面雷达波

- 四个相同波纹实例。
- 单圈周期 `8s`，相邻实例错峰 `2s`，使用负延迟初始化不同相位。
- 扩散使用 `linear` 匀速。
- 透明度关键帧为 `0% / 8% / 55% / 92% / 100%`。
- 对应桌面透明度为 `0 / 12% / 6% / 2% / 0`。
- 只保留 `1px` FileDock 青绿色细线；删除同色柔光和其他阴影。

### 移动端与减少动态效果

- 移动端保持同一范围、数量、周期和错峰，只把峰值从 `12%` 降至 `8%`。
- 移动端中段和外段按相同比例降低为约 `4%` 和 `1%`，终点为 `0`。
- 减少动态效果模式停止所有雷达与节点动画，只显示三圈 `5% / 3% / 1%` 静态雷达环。
- 三圈静态环分布在中心、中段和外侧，并使用同一对角线终点参数。

### 房间节点

- 雷达波经过节点时不触发任何联动效果。
- 节点继续是纯展示元素，无悬停、点击、提示或焦点行为。
- 稳定节点呼吸峰值从 `1.08` 提高到 `1.12`。
- 呼吸周期继续覆盖 `2.8～4.2s` 并保持错峰；圆内数字和边框跟随缩放，四位房间号标签不动。
- 中心头像不呼吸，节点不恢复外扩彩色光圈。

### 范围与质量

- 本阶段只修改正式首页雷达结构数量、终点计算、雷达 CSS、节点呼吸峰值和增量文档。
- 不修改首页布局、后端、API、房间业务、节点生成与位置算法。
- 不新增用户文案或翻译键，不新增依赖。
- 不使用 Playwright；运行现有测试、生产构建和格式检查，视觉效果由人工浏览器验收。
