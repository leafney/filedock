# 文件工具栏搜索动画优化讨论

## 原始需求

用户希望继续优化房间文件工具栏：排序控件显示为“图标 + 排序”，文件筛选控件显示为“图标 + 筛选”，批量选择保持不变；三个右侧控件统一右对齐，中间搜索框占据剩余空间；搜索框获得焦点后从左侧固定位置向右扩展，覆盖并隐藏右侧三个控件，失去焦点后收回。

## 代码分析

- 当前工具栏顺序为范围切换、搜索、文件关系筛选、排序图标、批量选择。
- 文件关系和排序已使用 Ant Design Dropdown，排序当前只有图标按钮。
- 工具栏是 Flex 布局，搜索框通过 `flex` 占据剩余空间。
- 移动端和窄桌面已有换行断点，不能让搜索扩展动画覆盖这些断点下的控件。

## 讨论问答

### 1. 搜索扩展动画适用哪些设备？

- 建议：仅桌面端 `>=941px` 启用；窄桌面和移动端保持换行布局，搜索框独占一行，不覆盖筛选控件。
- 用户确认：采用该方案。

### 2. 动画参数和触发方式是什么？

- 建议：聚焦扩展 `220ms ease-out`，失焦收回 `180ms ease-in`；使用 `onFocus/onBlur` 控制状态；右侧控件淡出并设置 `pointer-events:none`，避免覆盖层下误操作。
- 用户确认：采用该方案。

### 3. 筛选和排序按钮文案如何处理？

- 建议：筛选固定显示“筛选”，排序固定显示“排序”，都使用图标 + 两字文案；不在按钮上显示当前选项，完整选项在菜单中显示并用 selectedKeys 高亮；批量选择保持现有图标和文字。
- 用户确认：采用该方案。

### 4. 搜索动画覆盖范围是什么？

- 建议：范围切换保持原位；搜索框左边界固定在范围切换右侧，右边界扩展到批量选择右侧；只覆盖筛选、排序、批量选择，不覆盖 Tabs、文件列表或页面其他区域。
- 用户确认：采用该方案。

## 最终共识

工具栏改为“范围切换 | 可扩展搜索框 | 右侧筛选/排序/批量组”。桌面端聚焦搜索时覆盖右侧操作组并淡出，失焦收回；窄桌面和移动端不启用覆盖动画。业务查询、筛选选项、排序选项、批量权限和国际化行为保持不变。
