## 原始需求

用户对轻量全域雷达波版本进行人工验收后提供 FileDock 页面截图和 PairDrop 首页截图，并提出：

1. FileDock 圆环向外扩散时线宽明显增加，中间与外圈看起来偏粗，希望进一步变细。
2. PairDrop 首页圆环宽度稳定、间距均匀、整体较平静，希望直接参考其雷达扩散效果。
3. FileDock 当前扩散频率仍偏快，持续观看会产生烦躁感。
4. 用户补充 PairDrop 地址 `https://pairdrop.net/`，并要求先分析其真实实现参数，再决定 FileDock 方案。
5. 本轮继续使用 `grill-me` 逐项确认，暂不直接修改代码。

## FileDock 当前问题分析

- 当前圆环是基础直径 `132px` 的 HTML 元素，使用 `1px border` 后通过 `transform: scale()` 放大到整个雷达范围。
- CSS 变换会同时放大元素和边框，因此外圈视觉线宽会随缩放倍数增加。把基础边框简单改成 `0.5px` 只能整体变细，不能解决“越往外越粗”。
- 当前四个圆环分别在 `8s` 内从中心放大到面板对角线 `105%`，相邻圆环错峰 `2s`。每个圆环独立完成全程缩放，视觉移动速度仍较明显。
- 当前节点呼吸已经使用 `1 → 1.12 → 1`，本轮不需要继续调整。

## PairDrop 实际实现分析

分析日期：2026-08-04。读取了 PairDrop 公开首页、主样式、界面脚本及 Canvas Worker 脚本：

- `https://pairdrop.net/`
- `https://pairdrop.net/styles/styles-main.css`
- `https://pairdrop.net/scripts/ui-main.js`
- `https://pairdrop.net/scripts/worker/canvas-worker.js`

### 渲染结构

- PairDrop 使用 `<canvas class="circles">`，不是 CSS 圆环，也不是 SVG。
- Canvas 绝对定位在页面背景，宽度覆盖视口。
- 正常模式在浏览器支持时把 Canvas 转移到 OffscreenCanvas Worker；否则在主线程绘制。
- 动画由 `requestAnimationFrame` 驱动，目标帧率为 `60fps`。

### 圆环参数

- 圆环数量为 8 圈。
- Canvas 固定线宽为 `2px`，线宽不会随半径增加。
- 普通颜色为灰色 `rgb(168 168 168)`。
- 普通基础透明度为 `0.3`；分享模式基础透明度为 `0.8`。
- 起始半径偏移为 `33px`。
- 圆环间距公式等价于：`round(max(视口宽度 × 0.6, 视口高度) ÷ 10)`。

### 位移与周期

- `speed = 0.5`，`fps = 60`。
- 动画完整相位周期为 `1000 / speed = 2000ms`。
- 每个 `2s` 周期内，整组 8 圈向外移动一个圆环间距。
- 周期结束时所有圆环身份无缝轮换：最外圈离开，内侧补入新圈；视觉上不会整体跳回中心。
- 一个逻辑圆环跨越 8 个间距约需 `16s`。

### 半径与透明度

- 第 `i` 圈半径为：`间距 × i + 当前相位位移 + 33px`，其中 `i` 从 7 到 0。
- 基础透明度随半径线性衰减：`max(0, baseOpacity × (1 - 1.2 × radius / max(width, height)))`。
- 半径超过第 7 个间距后，再乘以 `(8 × 间距 - radius) / 间距`，使最外圈在第 8 个间距处完全消失。
- PairDrop 的平静感主要来自固定线宽、8 圈等距、整组慢速平移和半径衰减，而不是独立圆环快速放大。

### 圆心与尺寸

- PairDrop 圆心横向位于视口中心，纵向位于页面底部页脚上方。
- FileDock 的中心头像是雷达视觉锚点，因此只参考 PairDrop 圆环算法，不照搬底部圆心。

## 完整问答记录

### 问题 1：如何解决外圈线宽随扩散变粗？

初始推荐答案：把 CSS `border` 圆环改为 SVG，并使用 `vector-effect="non-scaling-stroke"`，线宽设为 `0.65px`。

用户回答：确认可以改用非缩放描边，并提出可以直接参考 PairDrop 首页雷达扩散效果。

后续修订：分析 PairDrop 实际代码后发现其使用 Canvas，而不是 SVG。最终 Canvas 决策覆盖本问题中的 SVG 方案。

### 问题 2：是否先把周期改为 `12s`、每 `3s` 发射一圈？

推荐答案：四圈保持错峰，周期由 `8s` 调整为 `12s`，每 `3s` 发射一圈。

用户回答：要求先分析 PairDrop 首页的真实效果参数，再决定节奏。

最终决定：首版不采用 `3s / 24s` 的自定义慢速方案，先复现 PairDrop 的 `2s` 整组位移相位和约 `16s` 逻辑完整行程，验收后再调。

### 问题 3：是否改用 PairDrop 同类 Canvas 等距圆环模型？

推荐答案：改用 Canvas；8 圈等距；整组向外移动一个间距后无缝循环；先参考 PairDrop 参数，再结合 FileDock 品牌色。

用户回答：确认采用相同 Canvas 方案。动画首版先参考 PairDrop，不采用更慢的 `3s` 间距周期和 `24s` 完整行程。

### 问题 4：Canvas 固定线宽使用多少？

推荐答案：PairDrop 使用 `2px`，但考虑用户希望变细，建议 FileDock 使用 `1px`。

用户回答：首版先采用 PairDrop 的 `2px`。

### 问题 5：颜色与基础透明度如何设置？

推荐答案：颜色保留 FileDock 青绿色；透明度衰减公式参考 PairDrop；桌面基础透明度使用 `0.18`，低于 PairDrop 灰色的 `0.3`，避免青绿色在白色背景上过强。

用户回答：确认。

### 问题 6：圆环间距与半径是否采用 PairDrop 公式？

推荐答案：采用 `round(max(width × 0.6, height) ÷ 10)` 间距、`33px` 起始半径、8 圈等距、每轮整体外移一个间距、最外圈额外渐隐；圆心保持 FileDock 当前画布中心。

用户回答：确认。

### 问题 7：是否支持高清屏设备像素比？

推荐答案：Canvas 内部分辨率按设备像素比放大，绘制坐标继续使用 CSS 像素，视觉线宽保持 `2px`，避免 Retina 屏模糊或锯齿。

用户回答：确认。

### 问题 8：减少动态效果模式如何处理？

推荐答案：不启动 Canvas 动画循环，绘制 8 圈静态等距圆环，透明度继续按半径衰减；同时停止节点呼吸、进入和退出动画。

用户回答：确认。

### 问题 9：浏览器标签进入后台时是否暂停 Canvas？

推荐答案：页面不可见时停止 `requestAnimationFrame`；返回前台后从暂停相位继续，不发生时间跳跃；尺寸变化时重新计算并重绘；卸载时清理动画帧与监听器。

用户回答：确认。

### 问题 10：移动端基础透明度是多少？

推荐答案：桌面为 `0.18`，`768px` 以下为 `0.12`；圆环数量、`2s` 相位周期、间距公式和 `2px` 线宽不变。

用户回答：确认。

### 问题 11：节点呼吸是否保持上一轮参数？

推荐答案：保持 `1 → 1.12 → 1`、`2.8～4.2s` 五节点错峰、标签不缩放、无外扩光圈，并且不与 Canvas 圆环联动。

### 问题 12：首版是否实现 OffscreenCanvas Worker？

解释：OffscreenCanvas Worker 会把 Canvas 绘图从 React 和页面交互所在的主线程移到后台线程，可降低复杂绘图阻塞，但需要独立 Worker、消息通信和兼容处理。

推荐答案：首版不实现。当前每帧只绘制 8 个简单圆环，主线程开销低；先验证视觉，若出现掉帧再加入 Worker。

用户回答：确认。

用户回答：确认。

### 问题 15：是否创建独立增量讨论与 PRD？

用户回答：确认。

## 最终共享理解

### 渲染模型

- 旧 CSS 缩放圆环和刚讨论的 SVG 方案都被替代。
- 使用主线程 Canvas 绘制 8 个等距圆环。
- 首版不使用 OffscreenCanvas Worker。
- Canvas 是装饰层，位于节点和中心身份下方，不接收指针事件，不参与辅助技术语义。

### PairDrop 首版参考参数

- 8 圈。
- 固定 `2px` 线宽。
- `60fps` 目标帧率。
- 相位周期 `2s`；每周期整组向外移动一个间距。
- 逻辑圆环跨 8 个间距约 `16s`。
- 间距：`round(max(width × 0.6, height) ÷ 10)`。
- 起始半径：`33px`。
- 半径：`spacing × index + phaseOffset + 33px`。
- 透明度使用 PairDrop 的半径线性衰减和第 7～8 间距额外渐隐。

### FileDock 差异

- 圆心为雷达画布中心，与中心头像同心；不使用 PairDrop 的底部圆心。
- 颜色使用 FileDock 青绿色，不使用 PairDrop 灰色。
- 桌面基础透明度 `0.18`，移动端 `0.12`；不使用 PairDrop 普通模式 `0.3`。
- 节点继续使用 `1 → 1.12 → 1` 错峰呼吸，不与圆环联动。

### 生命周期与兼容

- Canvas 位图按设备像素比设置，绘制坐标和 `2px` 线宽按 CSS 像素计算。
- 页面进入后台后暂停，返回前台从原相位继续。
- 尺寸变化后更新 Canvas 位图、圆心、间距并立即重绘。
- 减少动态效果只绘制静态 8 圈，并停止节点动画。
- Canvas 上下文不可用时静默隐藏背景效果，首页功能不受影响。

### 范围与质量

- 本阶段只修改首页雷达背景渲染和对应文档；节点算法与业务不变。
- 不新增用户可见文案或翻译键。
- 不使用 Playwright；运行现有测试、TypeScript 构建和格式检查，Canvas 视觉由人工验收。
