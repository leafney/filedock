# 文件工作区头部布局优化讨论

## 原始需求

用户测试后提出房间页面文件工作区上部占用空间过大。截图中左侧标题区显示“文件工作区 / 房间文件”，右侧单独一行显示“添加文件 / 发送已有私密文件”。希望删除左侧标题内容，并把右侧操作按钮移动到文件 Tab 栏右侧，使“文件列表 / 文件动态 / 回收站”和文件操作按钮位于同一行，从而压缩中间区域顶部高度。

## 代码现状

- 文件工作区使用独立标题工具栏和独立 Tab 栏，占据两行。
- 标题工具栏左侧显示“文件工作区 / 房间文件”，右侧显示两个文件操作按钮。
- 三个 Tab 切换时，标题工具栏和两个操作按钮始终显示。
- 窄屏样式会隐藏标题副文案，并将两个操作按钮缩为图标按钮。
- 正式前端的两个标题翻译键只在该标题区使用。

## 逐项问答

### 问题 1：桌面端和窄屏端如何排列？

推荐答案：桌面端删除标题块，把两个操作按钮放到 Tab 栏最右侧；窄屏端保留图标按钮，空间不足时允许操作区自适应换行，避免挤压 Tab。标题不再恢复。

用户回答：确认。

### 问题 2：切换不同 Tab 时是否继续显示操作按钮？

推荐答案：保持现有行为，在“文件列表、文件动态、回收站”三个 Tab 下都显示“添加文件”和“发送已有私密文件”，只调整位置，不改变功能。

用户回答：确认。

### 问题 3：是否删除废弃的多语言标题键？

推荐答案：从正式前端简体中文和英文词典中同时删除 `fileWorkspace` 与 `roomFiles` 两个不再使用的键，不修改独立原型目录。

用户回答：确认。

## 最终共识

正式房间页面删除文件工作区标题工具栏，不再显示“文件工作区 / 房间文件”。将两个文件操作按钮合并到 Tab 头部右侧，桌面端同一行展示，窄屏端保留图标化样式并允许必要时自适应换行。按钮在全部三个 Tab 下保持可见，点击逻辑、权限、上传弹窗和私密文件复用逻辑不变。文件筛选区、列表内容区、文件动态和回收站内容不做功能修改。正式前端同步删除两个废弃的中英文翻译键。
