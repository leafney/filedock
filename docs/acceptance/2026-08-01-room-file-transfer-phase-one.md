# 房间文件传输一期人工验收记录

Related PRD: [docs/plan/2026-07-31-room-file-transfer-phase-one.md](../plan/2026-07-31-room-file-transfer-phase-one.md)

## 验收边界

- 验收方式：真实浏览器人工验收，不使用 Playwright 或其他浏览器自动化。
- 开发侧状态：代码、纯逻辑测试、前后端构建和 Go 全包回归已完成。
- 浏览器侧状态：待验收人员在真实局域网、多浏览器会话和不同视口下逐项勾选。
- 本记录不把静态代码检查或命令测试冒充浏览器人工验收结果。

## 验收准备

1. 启动最新 `bin/filedock`，准备至少五个相互隔离的浏览器会话。
2. 分别建立房主、共享成员、私密上传者、私密接收者和无关普通成员身份。
3. 准备小文件、大文件、Unicode 文件名文件和至少三个可批量上传的文件。
4. 分别使用简体中文和 English 执行核心流程。
5. 建议视口：桌面端不小于 1180 像素；平板端 761 至 1180 像素；移动端不大于 760 像素。

## 桌面端

- [ ] 顶栏显示房间号、成员数、剩余时间、容量、语言、二维码、申请通知和更多操作，且没有重叠。
- [ ] 页面显示左侧成员栏、中间文件工作区、右侧“一对一聊天后续开放”占位和底部传输栏。
- [ ] 文件区顶部仅保留“添加文件”和“发送已有私密文件”两个主要入口。
- [ ] 拖放区在已有文件列表上方仍清晰可辨，并能接收多文件拖放。
- [ ] 共享和私密文件分别成组，全部范围中共享组固定在前，两组可独立折叠和分页。
- [ ] 普通文件操作区只突出下载与三个点；其他低频操作位于三级点菜单。
- [ ] 待接收私密文件突出“接收并下载”和“拒绝”。
- [ ] 文件动态使用左侧主轴、右侧独立卡片，并能继续加载。

## 平板端

- [ ] 固定成员栏隐藏，成员按钮打开抽屉，关闭后焦点返回触发按钮。
- [ ] 文件主区与聊天占位区在可用宽度内重排，无页面级横向滚动。
- [ ] 搜索、范围、身份、排序和批量按钮可换行，English 长文案不遮挡主要操作。
- [ ] 弹层内容可滚动，底部确认操作始终可触达。

## 移动端

- [ ] 仅突出文件主区，不显示聊天主入口。
- [ ] 添加文件调用系统文件选择器，不依赖拖放。
- [ ] 共享、私密或匿名审计标签在文件卡中始终可见。
- [ ] 三个点打开底部操作面板，触控区域足够，关闭后焦点返回三个点按钮。
- [ ] 普通模式不显示复选框；进入批量模式后才显示复选框与批量操作栏。
- [ ] 待接收私密文件仍能直接执行接收并下载或拒绝。
- [ ] 底部传输栏展示上传或接收百分比，展开后能查看任务、取消上传和重新上传失败任务。

## 文件上传与复用

- [ ] 选择或拖放文件后先进入待发送区，不立即上传。
- [ ] 共享上传不要求接收者；私密上传必须选择至少一个其他成员。
- [ ] 多文件批次先整体预留容量，容量不足时整批不开始。
- [ ] 同时最多两个本地文件上传，其他文件显示等待状态并自动推进。
- [ ] 每个文件独立显示百分比、已传容量和速度；取消一个文件不影响其他文件。
- [ ] 单文件失败后“重新上传”创建新任务，旧失败任务不被复活。
- [ ] “发送已有私密文件”支持多文件和多接收者，并禁用已经拥有对应文件权限的成员。
- [ ] 历史复用不重新上传字节，也不增加房间已使用容量。
- [ ] 私密上传者发布共享前出现风险确认，确认后文件进入共享组且容量不重复增加。

## 接收与下载

- [ ] 接收者点击“接收并下载”后状态变为已接收并启动浏览器原生附件下载。
- [ ] 接收者拒绝后无法下载；上传者能看到拒绝状态，并可再次发送。
- [ ] 共享文件无需接收即可下载。
- [ ] 同一用户同时最多启动两个下载，其余批量下载任务排队。
- [ ] 传输栏显示服务端响应写出百分比；界面没有声称操作系统已经最终保存成功。
- [ ] Unicode 文件名和扩展名在浏览器保存对话框中正确显示。
- [ ] 下载失败后可以重新创建下载任务，无需上传者再次发送。

## 权限与时间轴

- [ ] 共享文件和共享事件对全部活动成员可见。
- [ ] 私密上传者和接收者看到完整文件名、私密编号和与自己相关的接收状态。
- [ ] 无关普通成员看不到私密文件、私密事件及相关数量。
- [ ] 无关房主只看到“私密文件#XXXX-XXXX”、参与者、大小、状态和时间，不出现原文件名、扩展名、MIME 或下载入口。
- [ ] 搜索原文件名不能命中房主匿名私密记录；搜索私密编号可以命中。
- [ ] 刷新页面后文件列表和文件动态仍存在。
- [ ] 成员退出、被踢或房间进入销毁状态后，新的上传、接收和下载立即被拒绝。
- [ ] 房主容量弹层显示共享、私密、预留、总使用和总容量；普通成员只显示总使用和总容量。

## 键盘、双语与减少动态效果

- [ ] 文件列表／文件动态以及全部／共享／私密支持方向键、Home 和 End 切换。
- [ ] 分组折叠、拖放选择按钮、复选框和主要操作可使用键盘触发。
- [ ] 房间更多菜单和文件菜单支持上下方向键、Home、End、Enter 和 Escape。
- [ ] 弹层限制 Tab 焦点，Escape 可关闭，关闭后焦点返回原触发控件。
- [ ] 进度控件由辅助技术识别为 progressbar，并读出当前百分比。
- [ ] 切换简体中文与 English 后没有缺失键、中文硬编码或布局溢出。
- [ ] 系统开启减少动态效果后，旋转和过渡动画停止。
