# FileDock 房间工作区交互原型

> **历史原型：** 此原型已过时，仅保留用于历史评审参考。当前界面、交互与业务行为以生产前端为准。

用于评审新版房间工作区布局与业务可见性，不属于生产前端。对应规格：
[docs/plan/2026-07-31-room-workspace-prototype.md](../../docs/plan/2026-07-31-room-workspace-prototype.md)。
文件列表交互优化另见
[docs/plan/2026-07-31-room-file-list-ux.md](../../docs/plan/2026-07-31-room-file-list-ux.md)。

## 隔离边界

- 不引用 `frontend/` 组件、样式、依赖或构建配置。
- 不调用 FileDock API、SSE、SQLite 或真实文件存储。
- 不修改现有路由、Vite、Go 静态资源嵌入与数据库。
- 不使用 CDN 或新增依赖；全部资源位于当前目录。
- 浏览器选择文件时只读取名称、大小、MIME 元数据，不读取内容。
- 状态仅存当前页面内存；刷新恢复固定夹具。只有语言选择写入 localStorage。

## 启动与测试

在仓库根目录执行：

```bash
python3 -m http.server 4173 --directory examples/room-workspace-prototype
```

打开 `http://127.0.0.1:4173/`。ES 模块要求使用 HTTP 服务，不能直接双击 HTML。

纯逻辑测试：

```bash
bun test examples/room-workspace-prototype/tests
```

## 主要演示流程

1. 在“全部／共享文件／私密文件”间切换；全部视图可分别折叠两个文件分组。
2. 点击“添加文件”或常驻拖放条，选择文件后再确认共享／私密范围与接收者。
3. 点击“发送已有私密文件”，多选自己上传的文件和新接收者，不重复增加容量。
4. 普通文件直接下载；低频操作位于三个点菜单；待接收私密文件直接接收或拒绝。
5. 点击“批量选择”后跨组选择文件；全部文件共同满足权限时才可批量下载或私密发送。
6. 在“文件列表／文件动态／回收站”间切换；任一视图均可拖入文件并在取消后返回原视图。
7. 移动端三个点打开底部操作面板；进入批量模式后固定上传栏替换为批量操作栏。
8. 点击成员切换一对一聊天；支持文字、表情、私密文件和共享文件引用。

## 原型演示控制器

右上角 `PROTOTYPE` 按钮打开控制器。支持：

- 切换房主／普通成员，重新执行文件与事件权限投影。
- 切换简体中文／English，当前状态与任务不重置。
- 切换正常、加入、PIN、审批、解散、被踢、错误与空状态。
- 切换回收站是否计入容量；关闭时配置免费额度。
- 注入上传、接收、未读消息、已读回执和恢复申请事件。
- 重置固定夹具或隐藏控制器。隐藏后按 `Alt+D` 恢复。

截图前应隐藏控制器，避免评审工具遮挡业务界面。

## 已验证业务规则

- 共享文件全员完整可见；后加入成员也能看到既有共享文件。
- 私密文件仅发送者与接收者完整可见；无关普通成员完全不可见。
- 房主对无关私密文件只看到稳定别名、参与者、大小、状态和时间，不能下载。
- 文件列表、动态和回收站复用同一权限投影。
- 房主容量详情含共享、私密、上传预留和回收站细分；普通成员只见总量。
- 默认文件列表不显示复选框；批量操作严格采用全部已选文件的共同权限。
- 房主匿名私密投影只能按稳定编号搜索，隐藏原名不会命中搜索。
- 回收站计入时免费额度无效；不计入时只有超出免费额度部分占房间容量。
- 房主强制回收的文件由上传者申请恢复；房主审批；恢复前检查容量。
- 已读与下载状态分离；页面隐藏时不自动标记聊天已读。

## 已知限制

- 上传、下载、速度、剩余时间、失败与重试均为前端定时模拟。
- 不读取或传输文件内容，不实现哈希、秒传、分块、Range 或断点续传。
- 图片消息使用原型占位预览，不处理真实图片。
- 原型已读状态仅存内存。生产设计必须以 SQLite 服务端已读游标为事实来源，不能使用 localStorage 作为已读事实来源。
- 加入、PIN、审批、解散、被踢与错误页只演示可观察状态，不发送网络请求。
